# Plan: Extract SQL DB init from db.py, remove migrations

## Goal
Separate schema definition and initialization into its own file (`schema.py`), and strip all migration code (V1-V4) and the `meta` table from `db.py`. The result: `db.py` contains only runtime DB operations; `schema.py` handles schema creation on a fresh database.

## Changes

### 1. Create `src/lucas_v2/schema.py`
Move from `db.py`:
- `_TABLES` (lines 6-40)
- `_INDEXES` (lines 43-46)
- `_FTS_STMTS` (lines 50-67)
- `_SCHEMA` (line 70)
- `init_schema()` (lines 79-240) — **simplified**: remove all migration V1-V4 code and the `meta` table logic.

The simplified `init_schema()` will:
1. `PRAGMA foreign_keys=ON`
2. Create tables (`channel`, `video`, `transcript_chunk`)
3. Create indexes
4. Create FTS5 virtual table + triggers
5. No `meta` table, no migration blocks, no FTS rebuild flag

The FTS rebuild-once logic (lines 229-239) used the `meta` table to track whether an initial rebuild was done. Without `meta`, we can either:
- Always rebuild FTS on init (safe but slow for large DBs), or
- Drop the rebuild logic entirely (the triggers handle incremental sync; the initial build happens naturally as rows are inserted)

**Decision:** Drop the `meta`-based rebuild. FTS triggers handle sync from the start. If a user has an existing DB, they already have FTS data; if fresh, inserts populate it. This is safe because `CREATE TABLE IF NOT EXISTS` + triggers mean FTS stays in sync.

### 2. Modify `src/lucas_v2/db.py`
- Remove `_TABLES`, `_INDEXES`, `_FTS_STMTS`, `_SCHEMA` constants
- Remove `init_schema()` function entirely
- Keep: `connect()`, `search_chunks()`, `upsert_channel()`, `upsert_video()`, `replace_chunks()`, `video_exists_ok()`, `video_exists()`

### 3. Update `src/lucas_v2/__init__.py`
Change import on line 32:
```python
# Before:
from lucas_v2.db import connect, init_schema, upsert_channel, upsert_video, replace_chunks, video_exists

# After:
from lucas_v2.db import connect, upsert_channel, upsert_video, replace_chunks, video_exists
from lucas_v2.schema import init_schema
```
